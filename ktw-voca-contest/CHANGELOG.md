# 변경 이력

## 초기 요구사항

- 8개 레벨, A/B형 시험지와 정답지 총 32개 제작
- DAY 2~8 선정 데이터 사용
- 예시 한글 파일의 시험지 디자인 참고

## 서식 개선

- 표 테두리 표시
- No 열을 넓혀 가로 표시
- 모든 셀 가로·세로 중앙정렬
- 제목을 별도 남색 박스로 분리하고 중앙 배치
- Class·Name·A/B형을 다음 줄에 배치
- 로고를 바닥글에 고정해 다음 페이지로 밀리지 않게 변경
- 첫째·둘째 페이지 표 높이를 각각 조정

## 난이도 개선

- 각 단어의 기존 난이도 값을 보존
- ★ 단어를 앞으로, ★★를 중간, ★★★를 뒤로 실제 배열 변경
- 같은 난이도 안에서는 DAY와 기존 순서 유지
- 정렬 후 번호 재부여

## 출제 방식 개선

- 초기에는 Word/Meaning 칸을 지그재그로 비웠음
- 이후 문제를 별표 옆 한 칸으로 통일
- 최종 방식은 홀수 영어, 짝수 한글 뜻을 같은 문제 칸에 혼합 표시
- 옆 답안 칸은 항상 빈칸
- 정답지는 Word와 Meaning 모두 표시

## 잘림과 페이지 폭 개선

- 긴 Meaning이 줄바꿈될 때 잘리는 문제 수정
- 문자열과 셀 너비·높이를 계산해 글자 크기를 자동 조절
- 표의 OOXML 격자 너비와 전체 너비를 고정
- Word가 내용에 따라 표를 화면 밖으로 확장하지 못하게 설정

## 최종 검증

- 레벨별 독립 생성으로 메모리 누적 문제 방지
- 레벨별 4개 파일씩 검증
- 총 32개, 오류 0개
