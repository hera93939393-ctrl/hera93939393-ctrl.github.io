# KTW VOCA MASTER CONTEST 시험지 제작 PRD

## 1. 목적

DAY 2~8 단어에서 레벨별 선정 단어를 사용해 A/B형 시험지와 정답지를 제작한다. 학생이 쉬운 문제부터 어려운 문제까지 순서대로 풀 수 있도록 기존 난이도 값을 기준으로 문항을 재배열한다.

## 2. 대상 레벨

| 코드 | 공식 레벨명 | 구분 |
|---|---|---|
| BA | BASIC | 중등 |
| PA | PRE-INTERMEDIATE | 중등 |
| IA | INTERMEDIATE | 중등 |
| HA | HIGH | 중등 |
| JUPITER | JUPITER | 초등 |
| SATURN | SATURN | 초등 |
| URANUS | URANUS | 초등 |
| NEPTUNE | NEPTUNE | 초등 |

## 3. 파일 구성

- 레벨당 A형 시험지·정답지, B형 시험지·정답지: 4개
- 8개 레벨: 총 32개 DOCX
- 폴더: `KTW VOCA/{레벨}/{A형|B형}/`
- JUPITER B형: 96문항

## 4. 단어 선정 데이터

- 범위: DAY 2~8
- A/B형 데이터: `data/selected_A.json`, `data/selected_B.json`
- 레벨 내 중복 단어 제거 후 선정된 결과를 사용한다.
- 같은 난이도 안에서는 DAY와 기존 데이터 순서를 유지한다.
- 문항 배치 전 기존 `tier` 값을 기준으로 ★, ★★, ★★★ 순으로 정렬한다.
- 정렬 후 1번부터 번호를 새로 부여한다.

## 5. 출제 규칙

### 시험지

- 홀수 번호: 영어단어를 문제 칸에 표시하고 답안 칸은 빈칸
- 짝수 번호: 한글 뜻을 문제 칸에 표시하고 답안 칸은 빈칸
- 영어·한글 문제 모두 별표 바로 옆의 동일한 문제 칸에 표시

### 정답지

- 모든 번호에서 Word와 Meaning을 모두 표시
- 시험지와 동일한 단어 순서 및 번호 사용

## 6. 페이지와 표

- 앞면: 1~50번
- 뒷면: 51~100번
- 좌우 2단: `[No | 별 | Word/Meaning 문제 | 답안] × 2`
- 첫 페이지와 두 번째 페이지의 표가 페이지 하단까지 자연스럽게 채워져야 한다.
- JUPITER B형의 남는 4문항 칸은 비워 둔다.

## 7. 시각 디자인

- 제목은 별도의 남색 박스로 한 줄 중앙 배치
- 제목: `KTW VOCA MASTER CONTEST`
- 제목 아래 Class, Name, A/B형 입력 영역
- 첫 페이지 안내 문구:
  - `★ Basic / ★★ Challenge / ★★★ Master (쉬운문제부터 차근히 풀어보세요! 끝까지 포기하지 않는것이 가장 중요합니다:))`
- 로고는 페이지 바닥글 중앙에 고정
- 모든 표는 페이지 안쪽 폭보다 좁은 고정 너비
- 모든 표·셀·텍스트는 가로·세로 중앙정렬
- 표 자동 확장 금지
- 별표는 전용 좁은 칸에 세로 배치, 행간 90%
- 긴 Word/Meaning은 자동 줄바꿈하고 필요 시 글자 크기와 줄 간격을 축소해 잘리지 않게 표시

## 8. 검수 기준

- 파일 수 32개
- DOCX 압축 구조 손상 없음
- 파일당 문제표 2개, 각 26행 × 8열
- 표 고정 너비 및 중앙정렬 속성 존재
- 셀 가로·세로 중앙정렬
- 안내 박스와 로고 존재
- 기존 난이도와 표시 별 개수 일치
- 난이도가 낮아지는 역전 없음
- 시험지 홀수 영어/짝수 한글 및 빈 답안 규칙 준수
- 정답지 Word/Meaning 원본 데이터와 일치
