## '터미널' 용어

(1) mkdir = make directory, 새 디렉토리(폴더)를 만드는 명령어<br>
예> mkdir project (project라는 폴더 만들어줘!)
(2) cd = change directory, 디렉토리를 이동하는 명령어<br>
 예> cd project (project 폴더로 이동해줘!)
(3) pwd = 현재 위치한 경로를 출력
(4) touch = 빈 파일을 새로 만들거나 파일의 수정 시간을 갱신. 
 예> touch README.md

##  'GitHub / Git' 용어

git init = 현재 폴더를 git 저장소(repository)로 초기화
clone = 원격 저장소(remote repository)를 내 컴퓨터로 복제해오는 것
add = 변경한 파일을 커밋할 준비 상태(staging area)로 올리는 것. 예: git add .
commit = staging area에 올린 변경 내용을 하나의 저장 단위(기록)로 남기는 것
push = 로컬(내 컴퓨터)의 커밋을 원격 저장소(GitHub)로 업로드
pull = 원격 저장소의 최신 내용을 로컬로 가져와서 병합
branch = 원본 코드에서 분리된 독립적인 작업 흐름(가지). 기능 개발이나 실험할 때 사용
merge = 서로 다른 브랜치의 변경 내용을 하나로 합치는 것
checkout = 다른 브랜치나 커밋으로 이동하는 것. 예: git checkout main
status = 현재 변경된 파일, staging 상태 등을 확인. 예: git status
fork = 다른 사람의 저장소를 내 계정으로 복제해서 독립적으로 관리하는 것 (GitHub 웹 기능)
pull request (PR) = 내가 작업한 브랜치를 원본 저장소에 합쳐달라고 요청하는 것
